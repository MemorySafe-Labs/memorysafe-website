BETA LOCAL GRATUITO

Abra espaço para a memória.

Escolha seu assistente. Instale o beta local gratuito. Sem cadastro, sem complicar.

Claude Desktop
Baixar para Claude Desktop

No Claude Desktop: Settings → Extensions → Advanced settings → Install Extension… Selecione o arquivo baixado. No Windows, não dê duplo clique no arquivo.

Codex

Com a ferramenta de linha de comando do seu assistente instalada, execute:

codex plugin marketplace add MemorySafe-Labs/memorysafe-plugin
codex plugin add memorysafe@memorysafe
Claude Code

Com a ferramenta de linha de comando do seu assistente instalada, execute:

claude plugin marketplace add MemorySafe-Labs/memorysafe-plugin
claude plugin install memorysafe@memorysafe
