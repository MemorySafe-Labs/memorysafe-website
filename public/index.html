01 — THE PROBLEM

AI has a memory problem. Three of them.

Groundhog Day

Every chat starts at zero. You re-type your tools, your rules, your deadlines — every session, in every app.

Scattered memory

Claude knows some of it, Codex another slice, Cursor nothing. Your context is fragmented across vendors that don’t talk to each other.

Memory you don’t own

Vendor memory lives on their servers, on their terms. You can’t open it, back it up, or take it with you.

02 — HOW IT WORKS

One file. Three verbs.

Deliberately boring infrastructure: capture facts, keep them in a file you own, recall them when they matter.

1 · Capture

As you work, MemorySafe saves concise, durable facts — decisions, preferences, deadlines. Automatically if you turn that on, or only when you say “remember this.”

2 · Store

Everything lands in one database file on your computer. Open it, back it up, review it in the local dashboard.

3 · Recall

Your assistant searches memory before it answers, and only the facts it needs enter the conversation. Memories are never pruned for being old.

You stay in charge of the verbs. Protect what must not change. Remove a memory from recall. Review conflicts when facts collide — nothing is silently overwritten.

04 — PRIVACY

Private by architecture, not by promise.

Most privacy pages ask you to trust a policy. Ours asks you to look at a file path.

Read the code on GitHub ↗

Nothing uploaded by MemorySafe

Your memory database stays on your computer. No account, no sync, no MemorySafe server behind the free plugin.

You hold the keys

Protect locks a memory against change. Forget removes it from recall. The local dashboard shows what’s saved and what changed.

No sensitive capture

Secrets, credentials, payment and government IDs, health data: never captured, in any mode.

Honest limits

A connected AI service still processes the context you choose to share, and forgetting removes a memory from recall — not from history or backups. We say both plainly.

BEFORE YOU ASK

A few things, made clear.

Does the free version work across my devices?

The free plugin keeps its database on the computer where you install it. It can be shared by supported assistants on that computer. Cross-device memory is what the hosted edition does; it is available now, free during the beta.

What does “local” actually mean?

The memory database stays on your computer. A connected AI service can still process the context you choose to share under its own terms. Local storage doesn’t mean the AI service itself runs locally.

Can I change my mind about a memory?

Use the local dashboard to review saved memories, inspect changes, manage protection, and remove memories from recall. Removing a memory from recall does not completely erase history or backups.

Are the advanced memory features available yet?

We’re testing tools to prioritize memories automatically: what to keep, revisit, or set aside. They’re being built into the hosted edition and aren’t included in the free local plugin.
